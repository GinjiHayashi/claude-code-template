# 用語集

> プロジェクト固有の用語だけを書く。実装の詳細や設計判断は書かない。
> 「コード上の名前」は、コード・ファイル名・テスト名で使う英語名である（PLAN-21）。小文字の単語を `_` でつないで書き、使う場所の命名規則（architecture.md、DOC-04）に合わせて形を変える。ローマ字は使わない。

| 用語 | 定義 | コード上の名前 | 使わない言い換え |
|---|---|---|---|
| 図形 | 描く立体。ドーナツ、立方体、メビウスの帯のどれか | shape | 画像、モデル、オブジェクト |
| ドーナツ | 図形の1つ。円を、その円と離れた軸の周りに1周させてできる形 | torus | 円環、リング |
| 立方体 | 図形の1つ。6つの正方形の面で囲まれた形 | cube | 箱、キューブ |
| メビウスの帯 | 図形の1つ。帯を半回転ねじって両端をつないだ、表と裏の区別がない面 | mobius_strip | メビウスの輪 |
| フレーム | アニメーションの1コマ。画面の高さと同じ数の、幅と同じ長さの文字列 | frame | コマ、画面 |
| マス | フレームの中の1文字分の位置 | cell | ピクセル、画素 |
| 回転角 | 図形を2つの軸の周りに回した角度の組。単位はラジアン | rotation | 角度、向き |
| 投影 | 3次元の点を、画面のマスの位置に変換すること | projection | 射影、変換 |
| 明るさ | 面が光源に向いている度合い。明るさの文字を選ぶもとになる | luminance | 輝度、光量 |
| 明るさの文字 | 明るさを表す12段階の文字 `.,-~:;=!*#$@`（左ほど暗い） | shade_chars | パレット、濃淡記号 |
| 奥行きバッファ | マスごとに、それまでに描いた一番手前の点の近さを覚えておく表 | depth_buffer | Z バッファ |
| フレームレート | 1秒あたりに描くフレーム数 | fps | 速度、更新頻度 |
| 起動オプション | 起動するときに指定する、図形・画面の幅と高さ・フレームレート・描くフレーム数 | launch_options | 引数、設定 |
| 再生環境 | アニメーションの再生が使う、画面に書く手段・待つ手段・時刻を得る手段の組 | playback_environment | 端末、IO |
| 描くフレーム数 | 起動してから終わるまでに描くフレームの数。指定がなければ Ctrl+C まで描き続ける | frame_count | 枚数、回数 |
| 表面の点 | 図形の表面から一定の間隔で選んだ点。投影してマスに描く単位 | surface_point | 頂点、サンプル |
| 面の向き | 表面の点で、面に垂直な長さ 1 の向き | normal | 法線ベクトル、向きベクトル |
| 光源 | 面を照らす光が来る向き。位置は持たず、向きだけで表す | light_direction | ライト、照明 |
| 視点 | 図形を見る位置。画面の手前の、図形の中心の正面にある | viewpoint | カメラ、目 |
| 近さ | 表面の点が視点にどれだけ近いかを表す値。大きいほど手前 | closeness | 深度、Z 値 |
| 外接球の半径 | 図形の中心から一番遠い表面の点までの距離。どの図形でも同じ値にそろえる | bounding_radius | 大きさ、サイズ |
