# 用語集

> プロジェクト固有の用語だけを書く。実装の詳細や設計判断は書かない。

| 用語 | 定義 | 使わない言い換え |
|---|---|---|
| 幹事 | 会計を立て替え、参加者から集金する人。参加者の1人として人数に含める | 主催者、代表者 |
| 合計金額 | お店に支払った総額（円、税込み） | 総額、会計 |
| 1人あたりの額 | 参加者1人が払う金額。幹事負担では幹事以外の参加者が払う額、多めに集めるでは幹事を含む全員が払う額 | 単価、割り前 |
| 端数 | 合計金額を人数で割ったとき、100円単位にそろわない部分 | 余剰、小数 |
| 幹事負担 | 1人あたりの額を100円単位で切り捨て、不足分を幹事が払う方式 | 切り捨て方式 |
| 多めに集める | 1人あたりの額を100円単位で切り上げ、全員が同額を払う方式 | 切り上げ方式 |
| 余り | 「多めに集める」で、集めた額が合計金額を超えた分 | おつり、超過分 |
| 方式 | 端数の扱い方。「幹事負担」と「多めに集める」の2つがある | モード、丸め方 |
| 人数 | 割り勘する参加者の数。幹事を含む | 参加者数、頭数 |
| 幹事の支払額 | 「幹事負担」で幹事が払う額。合計金額から幹事以外の参加者が払う額の合計を引いた額 | 幹事負担額、差額 |
