# アーキテクチャ・構造

## 構成要素と境界
> システムを構成する要素と、それぞれの責務。

| 要素 | パス | 責務 |
|---|---|---|
| 計算 | `src/warikan/calc.py` | 合計金額と人数から、方式ごとの1人あたりの額・幹事の支払額・余りを計算する。入力値の型と許容範囲を検証する。入出力を持たない |
| コマンドライン | `src/warikan/cli.py` | コマンドライン引数を解析し、計算を呼び、結果を整形して標準出力に、エラーを標準エラー出力に書き、終了コードを返す |
| 起動口 | `src/warikan/__main__.py` | `python -m warikan` で起動されたとき、コマンドラインの処理を呼んで終了コードで終了する。それ以外の処理を持たない |

## 依存の向き
> どの要素がどの要素に依存してよいか。禁止する依存。

- 起動口 → コマンドライン → 計算 の向きだけを許す。
- 計算は、標準ライブラリ以外のどの要素にも依存しない。`sys`、`argparse`、`print` など入出力に関わるものを使わない。
- 実行時の依存ライブラリの制約は、tech.md の「技術的な制約」に従う。

## ディレクトリ構成
> ソースコードとテストの配置。

```
pyproject.toml          プロジェクト設定（依存、pytest、Ruff）
uv.lock                 uv が生成するロックファイル（手で編集しない）
.gitignore
src/warikan/            パッケージ本体（構成要素の表を参照）
tests/                  テスト（ファイル名は「命名規則」を参照）
```

## 命名規則
> ファイル、モジュール、関数などの命名規則。

- モジュール、関数、変数は `snake_case`、クラスは `PascalCase`、定数は `UPPER_SNAKE_CASE` とする（PEP 8）。
- テストファイルは `tests/test_<モジュール名>.py`、テスト関数は `test_<DES の ID>_<項目番号>_<内容>`（例: `test_des001_1_typical_split`）とする（TEST-09）。
- 用語集（glossary.md）の用語は、コード上では次の英語名で表す（CODE-04）。

| 用語 | コード上の名前 | コマンドラインでの表記 |
|---|---|---|
| 合計金額 | `total` | 1つ目の位置引数 |
| 人数 | `people` | 2つ目の位置引数 |
| 幹事 | `organizer` | - |
| 1人あたりの額 | `per_person` | - |
| 幹事の支払額 | `organizer_payment` | - |
| 余り | `surplus` | - |
| 方式 | `method` | `--method` |
| 幹事負担 | `organizer_pays` | `organizer-pays` |
| 多めに集める | `collect_extra` | `collect-extra` |
