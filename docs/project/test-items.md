# テスト項目

> 全 DES のテスト項目をこの1ファイルで管理する（TEST-08）。DES ごとに `## DES-001 <設計名>` の見出しを1つ作り、その下に3分類の表を置く。項目番号は DES の中で3つの表を通して1から振り、欠番を再利用しない。
> 異常系・境界値・敵対的入力を必ず含める（TEST-11）。テストの説明には `DES-001 #1` の形で番号を書く（TEST-09）。
> 「保持」は、変更前のコードでも成功する、既存の振る舞いが変わらないことの確認の項目に付ける（TEST-21）。
> DES を改訂したら、変わる項目は上書きし、なくなる項目は行を消して番号を欠番にする（PLAN-22）。DES が retired になったら、見出しの末尾に `（retired）` を付けて表は残す（PLAN-24）。
