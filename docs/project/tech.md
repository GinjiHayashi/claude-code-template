## 技術的な制約
> 書くこと: 使ってはいけない技術、守るべきバージョン、性能やセキュリティ上の制約。

- 実行時の依存ライブラリは追加しない（開発用の依存は pytest、pytest-cov、Ruff だけ）。
- 関数の引数と戻り値には型ヒントを付ける。
- 描画計算（回転角と画面の大きさから1フレームの文字列を作る関数）は、標準出力・時間・端末に依存させない。同じ引数なら必ず同じ結果を返す純粋な関数とする。
- 画面への出力と時間待ちは、外から差し替えられるようにし、テストで実際に待たずに済むようにする。
- 小数どうしの比較には `math.isclose` または `pytest.approx` を使い、`==` で比べない。
- 終了するとき（Ctrl+C を含む）は、必ずカーソルの表示を元に戻す。
