## 開発コマンド
> 書くこと: 各操作の正確なコマンド。hook や Skill はここに書かれたコマンドだけを実行する。該当しない操作は「なし」。表の操作名は hook が読むため変えない。コマンドに `|` を含める場合はスクリプトにまとめる。

| 操作 | コマンド |
|---|---|
| 依存関係のインストール | `uv sync` |

| リント | `uv run ruff check .` |
| フォーマット | `uv run ruff format .` |
| フォーマット（1ファイル指定） | `uv run ruff format` |
| フォーマット対象の拡張子 | `.py` |
| ビルド | なし |
| 起動 | `uv run python -m warikan` |

## 技術的な制約
> 書くこと: 使ってはいけない技術、守るべきバージョン、性能やセキュリティ上の制約。

- 実行時の依存ライブラリは追加しない（開発用の依存は pytest、pytest-cov、Ruff だけ）。
- 関数の引数と戻り値には型ヒントを付ける。
- 金額の計算に `float` を使わない。`int` の範囲で計算する（切り上げは `-(-a // b)` のように整数演算で行う）。
- 計算部分（入力値から結果を出す関数）と、コマンドライン入出力の部分を別モジュールに分け、計算部分は入出力に依存させない。
- 実行は1回あたり1秒以内に終わること。
