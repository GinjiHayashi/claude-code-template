# REQ-002 多めに集めるで割り勘を計算する

## 種別
> 機能要件 / 非機能要件 のどちらか。

機能要件

## 内容
> 何ができるべきか、どうあるべきか。1つの要件に1つの内容だけを書く。

合計金額と人数を指定し、方式に「多めに集める」を指定してコマンドを実行すると、1人あたりの額と余りを表示する。

計算規則は次のとおりとする。

- 1人あたりの額 = 合計金額 ÷ 人数 を100円単位で切り上げた額
- 余り = 1人あたりの額 × 人数 − 合計金額

## 根拠
> overview.md のどの目的・課題・成功基準に対応するか。見出し名で参照する。

- 目的（1人あたりの支払額をすぐに出す）
- 背景・解決したい課題（切り上げると余りをどうするか毎回迷う）
- 成功基準（10,000円・3人・多めに集めるの例、割り切れる場合の例、検算式）

## 受け入れ基準
> 満たせば要件を達成したと判定できる条件。判定できない表現（「適切に」「十分に」など）は使わない（DOC-20）。

以下の受け入れ基準は、すべて方式に「多めに集める」を指定した場合とする。

- 合計 10,000円・3人で実行すると、標準出力に「1人あたり 3,400円」と「余り 200円」が含まれ、終了コードが 0 になる。
- 合計 9,000円・3人のとき、標準出力に「1人あたり 3,000円」と「余り 0円」が含まれる。
- 合計 10,050円・1人のとき、標準出力に「1人あたり 10,100円」と「余り 50円」が含まれる。
- 人数 1〜100 のすべてと、合計金額 1、99、100、101、9,999、10,000、999,999、1,000,000 のすべての組み合わせで、「1人あたりの額 × 人数 − 余り = 合計金額」が成り立ち、1人あたりの額が100の倍数で、「（1人あたりの額 − 100）× 人数 < 合計金額 ≤ 1人あたりの額 × 人数」を満たす（余りは 0 以上 100 × 人数 未満になる）。
- 金額の表示形式は REQ-001 と同じとする。

## 対象外
> この要件に含めないこと。

- 余りの使い道（返金、次回への繰り越しなど）の提案
- 不正な入力の検出とエラー表示（REQ-003）
