# REQ-003 不正な入力をエラーにする

## 種別
> 機能要件 / 非機能要件 のどちらか。

機能要件

## 内容
> 何ができるべきか、どうあるべきか。1つの要件に1つの内容だけを書く。

入力が不正なときは計算せず、どの値がなぜ不正かを示すエラーメッセージを標準エラー出力に表示し、終了コード 1 で終了する。

整数として受け付けるのは、半角数字（0〜9）だけからなる文字列とする。符号、空白、カンマ、アンダースコア、小数点、全角数字を含む文字列は「整数でない」とする。

不正な入力は次のとおりとする。

- 合計金額が整数でない、または 1〜1,000,000 の範囲外である
- 人数が整数でない、または 1〜100 の範囲外である
- 方式が「幹事負担」「多めに集める」のどちらでもない
- 合計金額または人数が指定されていない
- 余分な引数、または定義されていないオプションがある

## 根拠
> overview.md のどの目的・課題・成功基準に対応するか。見出し名で参照する。

- スコープ（入力が不正なときのエラーメッセージと終了コード 1、入力の許容範囲）
- 成功基準（不正な入力では終了コード 1 と、どの値がなぜ不正かを示すメッセージが出る）

## 受け入れ基準
> 満たせば要件を達成したと判定できる条件。判定できない表現（「適切に」「十分に」など）は使わない（DOC-20）。

- 次の各入力で（表中の数値は読みやすさのためカンマを付けているが、実際の引数はカンマなしの数字列とする。バッククォートで囲んだ値は、書いたとおりの文字列をそのまま引数に渡す）、終了コードが 1 になり、標準出力が空で、標準エラー出力に下表の「含む文字列」がすべて含まれる。

| 入力 | 含む文字列 |
|---|---|
| 合計金額 `abc`、人数 3 | 「合計金額」「整数」 |
| 合計金額 `3.5`、人数 3 | 「合計金額」「整数」 |
| 合計金額 `10,000`、人数 3 | 「合計金額」「整数」 |
| 合計金額 `１０００`（全角）、人数 3 | 「合計金額」「整数」 |
| 合計金額 10,000、人数 `+3` | 「人数」「整数」 |
| 合計金額 0、人数 3 | 「合計金額」「1〜1,000,000」 |
| 合計金額 1,000,001、人数 3 | 「合計金額」「1〜1,000,000」 |
| 合計金額 10,000、人数 `x` | 「人数」「整数」 |
| 合計金額 10,000、人数 0 | 「人数」「1〜100」 |
| 合計金額 10,000、人数 101 | 「人数」「1〜100」 |
| 合計金額 10,000、人数 3、方式 `foo` | 「方式」「幹事負担」「多めに集める」 |
| 合計金額 10,000、人数を指定しない | 「人数」「指定」 |
| 合計金額・人数をどちらも指定しない | 「合計金額」「指定」 |
| 合計金額 10,000、人数 3、余分な引数 5 | 「引数」 |
| 合計金額 10,000、人数 3、未定義のオプション `--foo` | 「オプション」 |

- 合計金額 1・人数 1、合計金額 1,000,000・人数 100 では、終了コードが 0 になる（許容範囲の両端はエラーにしない）。

## 対象外
> この要件に含めないこと。

- 不正な値を自動で補正して計算を続けること
- 複数の不正な値を一度にすべて報告すること（最初に見つけた1つを報告すればよい）

## 判断
> Claude が推奨案で決めた判断（PLAN-18）。人間は承認時にここを確認する。判断がなければ「（なし）」。

| 判断 | 選択肢 | 採用 | 理由 |
|---|---|---|---|
| エラーの出力先 | (a) 標準エラー出力 (b) 標準出力 | (a) | コマンドラインツールの慣例に合わせ、計算結果と混ざらないようにするため |
| 引数の不足・方式の誤りの扱い | (a) 不正な入力に含めて終了コード 1 (b) 引数解析ライブラリの既定（終了コード 2）に任せる | (a) | overview.md のスコープは不正な入力を終了コード 1 としており、例外を作らないため |
| 整数として受け付ける形式 | (a) 半角数字だけ (b) Python の `int()` が受け付ける形式すべて（`+3`、`1_000`、全角数字など） | (a) | 受け付ける範囲を利用者が予測できる形にし、実装の都合で結果が変わらないようにするため |
| 不正な値が複数あるとき | (a) 最初の1つを報告する (b) すべて報告する | (a) | 成功基準は「どの値がなぜ不正か」を示すことだけを求めており、30分の制約に合わせて単純にするため |
