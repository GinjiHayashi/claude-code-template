# REQ-005 アニメーションの再生

## 種別

機能要件

## 内容

起動オプションで決まった図形と画面の大きさで、回転角を進めながらフレームを描き続け、フレームレートを上限として待つ。描くフレーム数に達するか Ctrl+C を押すと、カーソルの表示を元に戻して終わる。

## 根拠

- overview.md「目的」: 図形が回り続けるアニメーションをターミナルに表示する。
- overview.md「スコープ（やること）」: 回転角の増分、フレームレートと待ち時間、描くフレーム数、Ctrl+C の扱い。
- overview.md「成功基準」: フレーム数に 3 を指定すると、3フレーム描いて終了コード 0 で終わる。
- tech.md「技術的な制約」: 終了するとき（Ctrl+C を含む）は、必ずカーソルの表示を元に戻す。

## 受け入れ基準

フレームの番号は 0 から数える。

1. n 番目のフレームは、1つ目の軸の回転角 0.04 × n ラジアン、2つ目の軸の回転角 0.02 × n ラジアンで描かれる（REQ-001 のフレームと一致する）。
2. 最初のフレームを描く前に、画面を消してカーソルを非表示にする（`ESC[2J`、`ESC[?25l`）。各フレームは、カーソルを左上に戻して（`ESC[H`）から書く。
3. 各フレームを書いた後、「1/フレームレート 秒 − そのフレームの計算と出力にかかった時間」だけ待つ。この値が 0 以下なら待たない。
4. `--frames 3` を指定すると、フレームをちょうど 3 つ書き、カーソルを表示に戻して（`ESC[?25h`）終了コード 0 で終わる。
5. 描くフレーム数の指定がないときは、Ctrl+C を押すまでフレームを書き続ける（1000 フレーム書いた時点で終わっていないことを確かめる）。
6. 描いている途中で Ctrl+C を押すと、標準エラー出力に何も書かず、カーソルを表示に戻して終了コード 0 で終わる。
7. 描いている途中で Ctrl+C 以外の例外が起きた場合も、カーソルを表示に戻してから終わる。

## 対象外

- 起動オプションの解析と検証（REQ-004）。
- 1フレームの文字列の中身（REQ-001）。
- ターミナルの大きさの自動検出（overview.md「非スコープ」）。

## 判断

| 判断 | 選択肢 | 採用 | 理由 |
|---|---|---|---|
| 画面の書き換え方 | (a) 最初に画面を消し、各フレームはカーソルを左上に戻して上書き (b) 毎フレーム画面を消す | (a) | 毎フレーム消すとちらつく。フレームは常に同じ大きさなので上書きで足りる |
| Ctrl+C 以外の例外のときの終了コードと表示 | (a) Python の既定（トレースバックを表示し、終了コード 1） (b) 独自に決める | (a) | スコープに定めがない。カーソルを戻すこと（tech.md の制約）だけを要件にし、それ以外は既定の動きに任せる |
