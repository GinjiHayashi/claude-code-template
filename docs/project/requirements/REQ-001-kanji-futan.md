# REQ-001 幹事負担で割り勘を計算する

## 種別
> 機能要件 / 非機能要件 のどちらか。

機能要件

## 内容
> 何ができるべきか、どうあるべきか。1つの要件に1つの内容だけを書く。

合計金額と人数を指定してコマンドを実行すると、「幹事負担」で計算した1人あたりの額と幹事の支払額を表示する。方式を指定しないときは「幹事負担」で計算する。

計算規則は次のとおりとする。

- 1人あたりの額 = 合計金額 ÷ 人数 を100円単位で切り捨てた額
- 幹事の支払額 = 合計金額 − 1人あたりの額 ×（人数 − 1）

## 根拠
> overview.md のどの目的・課題・成功基準に対応するか。見出し名で参照する。

- 目的（1人あたりの支払額をすぐに出す）
- 背景・解決したい課題（端数の扱いが毎回違う、切り捨てると集金額が足りない）
- 成功基準（10,000円・3人・幹事負担の例、割り切れる場合の例、検算式）

## 受け入れ基準
> 満たせば要件を達成したと判定できる条件。判定できない表現（「適切に」「十分に」など）は使わない（DOC-20）。

- 合計 10,000円・3人・方式指定なしで実行すると、標準出力に「1人あたり 3,300円」と「幹事 3,400円」が含まれ、終了コードが 0 になる。
- 合計 10,000円・3人・方式に「幹事負担」を指定したときも、上と同じ出力と終了コードになる。
- 合計 9,000円・3人のとき、標準出力に「1人あたり 3,000円」と「幹事 3,000円」が含まれる。
- 合計 250円・3人のとき、標準出力に「1人あたり 0円」と「幹事 250円」が含まれる。
- 合計 10,050円・1人のとき、標準出力に「1人あたり 10,000円」と「幹事 10,050円」が含まれる。
- 人数 1〜100 のすべてと、合計金額 1、99、100、101、9,999、10,000、999,999、1,000,000 のすべての組み合わせで、「1人あたりの額 ×（人数 − 1）+ 幹事の支払額 = 合計金額」が成り立ち、1人あたりの額が100の倍数で、「1人あたりの額 × 人数 ≤ 合計金額 < （1人あたりの額 + 100）× 人数」を満たす。
- 金額の表示は、3桁ごとにカンマで区切った整数に「円」を付けた形（例: 3,300円）とする。

## 対象外
> この要件に含めないこと。

- 「多めに集める」の計算（REQ-002）
- 不正な入力の検出とエラー表示（REQ-003）
