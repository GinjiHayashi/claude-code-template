# DES-007 メビウスの帯

> 実装レベルの粒度で書く。コード本体は書かない。必須項目の定義の正本は guidelines/planning.md。

## 対応要件

REQ-007 の受け入れ基準 1〜3 のすべて。あわせて、DES-004 から回された REQ-004 基準 1 の `mobius-strip` を選べる部分を担う。

- 基準 1: `SHAPES` に `mobius-strip` を足す。起動オプションの選択肢と、選べない名前を指定したときの一覧は `SHAPES` のキーから作られる（DES-004）ので、それだけで両方に加わる。
- 基準 2: REQ-001 基準 1〜5 は、DES-001 の「全図形」の項目（#1・#2・#6・#7・#9・#10・#11）が、`mobius-strip` を `SHAPES` に足すことで対象にする（DES-006 と同じ考え方）。この DES では、メビウスの帯が `SHAPES` に入ること、帯の範囲にある点であること、帯の幅の両端の点、点の数の上限（DES-002）を確かめる。REQ-002 基準 1 は、DES-002 #2 のコマンドを使う DES-007 #12 で確かめる。
- 基準 3: 中心線の上の点を、中心線に沿う向きの角で 0 から 2π まで動かしたときの面の向きを確かめる。

## 概要

`spin.shapes` に、メビウスの帯の表面の点を作る関数 `mobius_strip` と、帯の上の1点を求める関数 `mobius_strip_point` を足し、選べる図形の一覧 `SHAPES` に `mobius-strip` の名前で加える。描画計算（`spin.rendering`）は変えない（overview.md「制約」）。

## データ構造

- モジュール内だけで使う定数（`spin.shapes`。名前を `_` で始め、公開しない）:
  - `_MOBIUS_RADIUS = BOUNDING_RADIUS × 2/3`: 中心線（xy 平面の上の、原点を中心とする円）の半径 R。
  - `_MOBIUS_HALF_WIDTH = BOUNDING_RADIUS / 3`: 帯の幅の半分 w。
  - `_MOBIUS_LENGTH_STEPS = 400`: 中心線に沿う向きの点の数。
  - `_MOBIUS_WIDTH_STEPS = 40`: 帯の幅の向きの点の数。
- 位置: `P(u, v) = ((R + v cos(u/2)) cos u, (R + v cos(u/2)) sin u, v sin(u/2))`。帯は中心線を1周する間に半回転ねじれる。
- 面の向き: `P` を `u` で微分した向き `P_u` と、`v` で微分した向き `P_v` の外積 `P_u × P_v` を、長さ 1 にしたもの。
  - `P_u = (−(v/2) sin(u/2) cos u − (R + v cos(u/2)) sin u, −(v/2) sin(u/2) sin u + (R + v cos(u/2)) cos u, (v/2) cos(u/2))`
  - `P_v = (cos(u/2) cos u, cos(u/2) sin u, sin(u/2))`
  - `abs(v) ≤ w < R` では外積の長さは 0 にならない。
- 表面の点: `u_j = 2π × j / 400`（j = 0〜399）、`v_k = −w + 2w × k / 39`（k = 0〜39。両端の ±w を含む）のすべての組で、`mobius_strip_point(u_j, v_k)` を j を外側の繰り返しにして並べる。点の数は 400 × 40 = 16000 点で、DES-002 の上限（30000 点）以下である。
- 一番遠い点: 原点からの距離の2乗は `R² + 2Rv cos(u/2) + v²` で、最大は `u = 0`・`v = w` のときの `(R + w)² = BOUNDING_RADIUS²` である。この点は表面の点に含まれる（REQ-001 基準 4）。
- 回転角 0 では、中心線が画面に平行な円になり、帯を正面から見る。

## 処理方針

- **1点（`mobius_strip_point`）**: データ構造の式で位置と、`P_u × P_v` を長さ 1 にした面の向きを求める。
- **表面の点（`mobius_strip`）**: データ構造の `u_j`・`v_k` の組ごとに `mobius_strip_point` を呼び、1つのタプルにまとめて返す。
- **1周で面の向きが反転すること（REQ-007 基準 3）**: 中心線の上（`v = 0`）では `P_u = (−R sin u, R cos u, 0)`、`P_v = (cos(u/2) cos u, cos(u/2) sin u, sin(u/2))` である。`u = 0` では面の向きが `(0, 0, −1)`、`u = 2π` では `cos(u/2) = −1`・`sin(u/2) = 0` なので `P_v` が反転し、面の向きは `(0, 0, 1)` になる。位置はどちらも `(R, 0, 0)` で同じである。面の向きは `u` の連続な式なので、途中で飛ばずに1周して −1 倍になる。
- **公開する1点の関数**: 基準 3 は「中心線に沿って連続に1周したとき」の面の向きを問う。表面の点のタプルには `u = 2π` の点がなく（`u = 0` と同じ位置だから）、並びの順に頼った確かめ方はテストが公開していない内部の並びに依存する（TEST-19）。そこで、帯の上の任意の1点を求める `mobius_strip_point` を公開し、テストはこれを通して確かめる。`mobius_strip` も同じ関数で点を作るので、テストした式と描く点が食い違わない。
- **点の数（400 × 40）**: 幅 80・高さ 24 で、帯の外縁（半径 1 の円）は横に約 42 マスの幅に描かれる。400 点なら、外縁が横向きに進む部分での点の間隔は約 0.33 マス（2π / 400 × 21 マス）、帯の幅（横に約 14 マス）の向きは 40 点で約 0.36 マスで、面に穴が空かない。試作では、より粗い 300 × 30 でも、回転角 (0, 0)、(0.5, 0.3)、(1.2, 0.7)、(2.0, 1.0) のフレームに目立つ穴はなかった。400 × 40 の1フレームの計算は約 0.022 秒（5回計った最短）だった（TASK-010 の「完了したこと」）。
- **同じ位置の2点**: `u_j` は 2π を含まないので、`(u, v)` と `(u + 2π, −v)` が同じ位置になる組は表面の点に現れない。近さが等しい2点の扱い（DES-001）に結果が左右されない。
- **明るさ**: 表裏の区別がない面も、DES-001 の `shade` が面の向きを視点の側にそろえてから計算する（REQ-007「対象外」、REQ-001 基準 8）。この DES では明るさの計算を足さない。
- 採用しなかった案:
  - 帯の上の点を求める関数を非公開にし、表面の点のタプルの並びから中心線の点を探して確かめる: テストが内部の並び（j と k の順、`v = 0` の点の位置）に依存する（TEST-19）。また 40 点の `v_k` には `v = 0` が含まれない。
  - 帯の幅を広くする（R = 1/2、w = 1/2 など）: `abs(v)` が R に近づくと中心付近で帯が細くつぶれ、ねじれが見えにくい。R : w = 2 : 1 は、ドーナツの中心円と管の半径の比と同じで、画面での大きさもそろう。

### 既存の振る舞いへの影響

変更するのは `src/spin/shapes.py`（関数と定数の追加）と、2つのテストファイル（テストの追加だけ）である。
- 保つ振る舞い: `torus`・`cube` が返す点、`SHAPES` が読み取り専用であること（DES-001 #24）、`SHAPES` に無い名前で `KeyError` になること（DES-001 #25）、`SHAPES` に `torus` と `cube` があること（DES-001 #22、DES-006 #1）、図形の名前の既定値 `torus`（DES-004 #1）。`spin.rendering`・`spin.cli`・`spin.animation`・`spin.__main__` は変えない。
- 変わる振る舞い: `SHAPES` のキーに `mobius-strip` が加わる。これにより次の既存の項目の対象が増えるが、既存のテストは `SHAPES` のキーと値をたどる書き方なので、変更しない。
  - DES-001 #1・#2・#6・#7・#9・#10・#11（全図形の項目）がメビウスの帯も確かめる（REQ-001 基準 1〜5、REQ-007 基準 2）。
  - DES-004 #5 の「`SHAPES` のすべてのキーが含まれる」の対象に `mobius-strip` が加わる（REQ-004 基準 4、REQ-007 基準 1）。
  - 起動オプションの図形の選択肢と `--help` の表示に `mobius-strip` が加わる（REQ-004 基準 1）。
  - DES-002 #2 の人間確認のコマンドが、`mobius-strip` の計算時間も表示する（REQ-002 基準 1）。
- なくなる振る舞い: なし。
- 既存のテストの変更・削除: なし（TEST-22）。
